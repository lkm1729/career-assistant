## 本轮变更

- AI_MATCH_JSON补充固定结构摘要：字符数、首字符类别、是否存在左花括号、JSON围栏、think标签。只包含程序枚举/计数/布尔值，不显示原文或JSON.parse异常；分类不代表语义判断。
- 发送确认新增retainFailedResponse布尔选项，默认关闭，只对当前运行有效，不保存在设置、草稿、正式历史或请求消息中。非布尔值拒绝。
- 仅在JSON解析失败、且该次选项严格为true时保留临时内存副本；取消、输出截断、过期资料/配置、成功匹配不保留。失败响应不进入数据库或日志。
- 临时副本绑定运行ID，5分钟主动超时与读取时到期检查；读取一次后主进程清除，UI关闭/离开页/下次匹配清除；页面已离开时异步完成的预览也丢弃。程序关闭后不恢复。
- API Key按实际本次凭证及JSON/URL转义形式在裁剪前遮蔽；不是通用PII/凭证识别或完整脱敏。最多32000正文字符（长文本取前24000和后8000，另加省略标记）。
- 查看需第二次确认；受信任IPC只返回指定本次运行预览。UI使用只读textarea，不渲染Markdown/HTML/链接，不请求外部资源，不提供自动上传或导出。查看不触发模型请求。
- 原始响应只在可选内存副本/显式查看窗口出现，不进入常规错误对象。GC语言仅保证移除应用引用，不承诺操作系统换页、崩溃转储或屏幕截图无痕。
- 不扩大0.10.3 JSON接受范围，不删除think标签，不从自然语言推断正式匹配结构，不自动重新格式化付费调用，不修改Gemini/Anthropic原有格式能力或流完成规则。
