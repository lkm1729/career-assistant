# O2 / 0.12.2 就近反馈与动态加载

日期：2026-09-17。对应用户第11、19项。O1/0.12.1已由用户实测确认功能正常，作为保留基线。
当前状态：实现、本机回归与发行验收完成，可交用户实测；未进入O3–O6。

## 本批章程与验收边界

- 岗位匹配、简历评分、设计简历、求职信：触发按钮下方显示旋转图标、渐变微光文字及真实阶段提示。生成按钮自身也有运行图标。
- 区分本地准备发送确认、正在运行、请求停止、成功和失败；不使用伪进度/伪百分比，不显示猜测的模型思考内容。
- 运行开始时只就近将本地反馈区带入视口，不持续跟随流式输出滚动，不要求用户返回顶部；正文调整区同步展示状态。
- 模型测试确认、运行状态、取消及结果放在对应模型卡片内；供应商探针的取消与结果放在供应商探针按钮旁。不再把这些交互集中在设置页面末尾。
- 单项资料/模型/供应商删除确认在目标行内；删除后在原位置保留一块可收起的结果。批量操作在对应列表工具栏旁反馈。
- 资料用途/发送选择的保存、文件导入、网页读取与本地补充，反馈跟随各自触发区域；真实错误继续显示结构化诊断。
- 取消控件必须在运行时可用：锁住输入和保存按钮，但不让上层disabled fieldset误锁取消按钮。使用即时ref锁阻止重复提交/重复取消。
- 减少动态效果时关闭旋转与渐变动画，保留可读文字；高对比模式不依赖透明渐变文字。
- 唯一主反馈区按阶段进行polite播报，镜像区域aria-live=off，流式正文不放在live区域中逐token播报。

## 安全与范围

本轮只修改渲染组件、状态和本地交互，不修改供应商协议、资料持久化格式、匹配/评分算法、历史契约或IPC权限。不新增网络来源或付费请求，不收集遥测。
O1逐项用途/网页授权/批量事务删除继续保留；“移除资料”仍是软移除，原文件和历史快照保持。
不实现匹配度新分数、删除网页提示、工作台清空、模型发现或性能专项；这些分别属于O3–O6。
未签名、独立干净机器和既有许可缺项不因本轮UI优化而关闭。

## 实现与自审要点

- src/ActionFeedback.tsx：固定消息、spinner/shimmer、可选取消与单次live播报的共用组件。
- src/WorkbenchFeedback.tsx：按当前页面解释实际准备/运行/完成状态，就近可见，不显示流式正文。
- src/App.tsx、src/panels.tsx：将禁用范围缩小到输入和正文编辑，保持反馈区的停止按钮可操作。
- src/useMatch.ts、src/useScore.ts、src/useAi.ts：准备阶段状态、取消状态及同步锁，成功后保留可见完成提示。
- src/MatchPanel.tsx、src/ScorePanel.tsx、src/ai-controls.tsx：原有概况也沿用动画，镜像不重复播报，不因其他页忙碌而错误显示本页动画。
- src/RegistrySettings.tsx：测试确认和反馈搬至卡片，显式锁定编辑操作但保留取消；删除结果留在相同行；本地保存继续不发网络请求。
- src/ProviderProbe.tsx：旁侧取消、请求结束后刷新记录，供应商配置改变清除过期的本次反馈。
- src/Materials.tsx：操作目标锚点、本地状态、逐项确认与移除结果占位；未使用页面底部全局通知替代就近结果。
- src/styles.css：主题一致的反馈卡，沿用reduced-motion并补高对比文字。

目录无Git仓库；改前副本：.test-data/o2-original-20260917-211209。只读差异核对与本轮自审，不宣称独立代理审查。未提交、推送或重置。
