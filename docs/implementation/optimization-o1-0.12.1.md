# O1 / 0.12.1 资料逐项用途与批量管理

日期：2026-09-17。范围：用户优化建议第 10、20 项；O2–O6 尚未实施。
状态：本批实现、全量单元/服务、桌面回归及打包验收完成；桌面48项已通过（含单独重跑），2项真实网页按计划跳过。

## 用户可见变化

- 点击“多选导入文件 / 图片”后，先列出待导入清单。每个文件/图片可分别选择“简历 / 经历”“目标岗位”“补充证据”，支持从清单移出单项及取消整次导入。
- 点击“确认用途并导入”后才进行本机读取、解析与保存。新导入项不自动勾选发送给 AI。
- 网页批量读取确认中，每条链接独立设置用途；在线简历可以选择“简历 / 经历”，个人项目可以选择“补充证据”。失败项不撤销已成功的其他项，也不自动重试。
- 设计简历新增项目网页入口，岗位匹配与求职信沿用同一资料组件；设计简历页的网页默认用途为补充证据。三个页面均支持本地粘贴替代网页读取。
- 所有资料卡都有用途选择器，导入后可修改；重启保存。用途变更不篡改原有来源、内容和历史运行快照。
- 四个工具的资料区提供“批量管理”：独立的待移除复选框、全选/取消全选、数量显示及整批确认。明确标注“发送给 AI”和“待移除”，二者互不影响。
- 批量移除沿用已有软移除语义：从本页活动清单移出，原始文件、旧历史快照以及数据库中的资料副本保留；不是安全擦除，也不承诺释放数据库大小。

## 数据与安全边界

- 沿用已有 materials 表、purpose 字段、revision 与 manifest 校验；不引入 schema 迁移、不清空既有资料。
- 原生文件选择框给主进程实际路径；渲染进程只收到随机文件 ID 和文件名。确认时只接受该页面本次选择中的 ID，用途逐项校验，拒绝任意路径、重复项、过期/跨页票据。票据15分钟有效、一次性消费，每页只保留一份。
- setPurpose 先检查页面、用途、资料版本，更新 revision。任何选中或未选中资料的用途变更都会使旧 manifest 失效；模型请求开始前重新检查。
- removeMany 在 SQLite BEGIN IMMEDIATE 事务中校验整批 ID/revision，全部有效才更新；一项过期/跨页则整批不移除。
- 新 IPC 与旧 IPC 一样校验可信渲染进程与服务空闲状态；生成/评分/匹配/探针或本地导入期间不允许修改正在使用的资料。
- 网页安全检查、明确网络授权、公共 DNS 单次授权、内网阻断、来源快照与提示注入隔离均保留。网页导入没有升级为脚本浏览器，也不绕过登录。
- 原文件和其他页资料未被删除；没有真实服务密钥、用户资料或原始供应商响应写入测试报告。
