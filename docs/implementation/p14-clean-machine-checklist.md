# 0.12.0 独立干净 Windows 验收（待执行）

本清单随测试版提供，并不代表已经在干净机器运行。建议 Windows 11 x64 独立虚拟机；Windows 10 22H2 x64 作为兼容目标另测。不要使用重要的真实资料或 API Key。

## 环境记录
- [ ] 日期、Windows 版本/build、x64 架构、是否新建虚拟机、是否标准用户。
- [ ] 环境没有预装 Node/npm/Python/Office，不预装 Google Sans/MiSans；全程断网。
- [ ] 核对 SHA256SUMS.txt；保留系统安全设置。不因未签名绕过企业安全策略，不关闭杀毒/证书验证。

## 新装与离线功能
- [ ] 运行 Setup-x64.exe，不要求管理员权限；正常完成并出现在开始菜单。
- [ ] 启动四个页面，中文可读，Google Sans 由安装目录加载；无字体联网请求。
- [ ] 修改四页虚构草稿、保存提示词副本；关闭重开保持隔离。
- [ ] 导入 acceptance-fixtures/fictional-resume.pdf，正文/页面图像可见。
- [ ] 导入 fictional-resume.docx，不需 Office，显示本地近似预览提示。
- [ ] 导入 fictional-ocr.png，识别出 CAREER/RESUME 与“工程/简历”（OCR 可能加空格）。
- [ ] 资料默认不自动发送，无模型配置时不会调用外网。
- [ ] 应用打开时再次运行安装器，拒绝覆盖、不强行关闭窗口。

## 覆盖安装与卸载
- [ ] 关闭应用，记录虚构草稿/提示词/资料及测试库备份。
- [ ] 再次安装同版，记录和草稿仍在。0.11.1 -> 0.12.0 的真实旧版隔离库升级应另记录；不要降级改写生产库。
- [ ] 正常卸载，只移除程序/快捷方式/登记，%APPDATA%\Career Assistant 数据仍在。卸载不是安全擦除。
- [ ] 重装后旧虚构资料仍可读取；删除测试库属于另行明确授权的动作，不是本脚本自动操作。

## 提交验收
记录每项通过/失败、错误码及截图。不要上传数据库、密钥或未脱敏个人材料。独立干净环境全部通过之后，才能关闭 P14 的该项；真实供应商兼容性是另一张验收表。

## 可选 Windows Sandbox 配置
同目录 `P14-Clean-Machine.wsb` 仅适用于已由管理员安装 Windows Sandbox 的机器，本任务未开启系统功能。配置只读映射本发行目录、关闭网络和剪贴板，不自动运行安装器；进入后按本清单人工操作。配置里的宿主路径是当前电脑绝对路径，换机器需先修改。关闭 Sandbox 会丢弃其虚拟机数据；它不能替代跨次启动的持久化虚拟机升级验收。
