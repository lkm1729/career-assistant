# 0.7.1 修正版复核（2026-09-15）

## 本次复核结论

上轮回复所称的“已完成”不能全部成立。复核时确认了三个实际缺陷，并用先失败、修复后通过的测试锁定：

- API Key 输入框未渲染眼睛按钮；此前只增加了未使用的 state/import/CSS。
- 保留 Key 只改了说明文字，后端仍然拒绝在地址变化时留空 Key。
- 模型协议下拉框虽然被移除，但旧模型协议仍能覆盖供应商协议。

0.7.1 已修复这三处。此版本仍停留在 P06 + P07，不开启 P08。
