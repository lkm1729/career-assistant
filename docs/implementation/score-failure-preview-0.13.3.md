# 评分失败响应本机诊断入口 · 0.13.3

日期：2026-09-19。用户已授权加入默认关闭、单次明确勾选后启用的临时诊断入口。该版本用于取得真实Claude评分失败响应，不宣称SEPARATOR_REQUIRED根因已确认或已修复。

## 交互与边界

1. 简历评分发送确认页新增“仅本次评分JSON失败时保留响应供本机诊断”，默认关闭，每次准备评分重新关闭，不存入设置或供应商请求。
2. 仅当流式协议正常返回完整正文、输入/配置快照仍有效、JSON解析抛AI_SCORE_JSON时，在主进程临时内存保留一份正文。不捕获HTTP错误、取消、流中断、证据不合法或成功评分。
3. 最多700000字符，保留中段便于定位语法问题；超过上限截取并明确提示不完整。当前已知API Key及其JSON/URL转义形式在截取前遮蔽，但不是完整个人信息脱敏。
4. 失败后点击查看，还需再次确认；按纯文本textarea呈现，不执行HTML/Markdown。可手动修改敏感文本，勾选已检查个人信息后才能点击复制；修改文本会撤销复制确认。
5. 5分钟到期、关闭/丢弃、离开评分页或准备下一次评分清除应用内副本。主进程读取是一次性的，渲染器按同一绝对过期时间清理显示；过期不重新请求供应商。
6. 不写响应到数据库、文件、日志或历史；不自动上传/发送给他人，不自动重试，不改变评分解析器。手动复制会写系统剪贴板，应用不会自动清除系统剪贴板；内存临时存放不是OS换页/崩溃转储安全擦除承诺。
7. 评分和岗位匹配诊断缓存独立，按runId一次读取；不重用匹配页32k首尾截断策略，以免评分语法错误的中段丢失。

## 使用步骤

打开简历评分，正常填写本页资料；点击开始评分，在确认页勾选“仅本次评分JSON失败时保留响应供本机诊断”，再手动确认发送。失败后在评分结果区点击“查看本次评分失败响应（仅本机）”，确认隐私提示后查看。可在纯文本框内手动脱敏，保留语法符号和换行，不格式化或修复JSON；勾选已检查个人信息后复制所显示文本，再决定是否分享。

默认关闭，每次只保留本次；5分钟到期或关闭/离开页面后不可恢复，无需反复收费重试。若已手动复制，系统剪贴板由用户管理。Release位于`release/0.13.3/`，校验和见`SHA256SUMS.txt`。
