## 新增与变更

- `package.json` / lockfile：0.12.0；`npm run package` 同时构建 NSIS 与 ZIP，旧0.11.1和0.11.0保留。
- 当前用户一键安装（oneClick/perMachine=false），不强制提升权限，不打包 elevate.exe，不在安装后自动运行。
- `build/installer.nsh`：覆盖默认强制结束进程行为；检测到同名应用或不确定结果则退出，要求用户自行保存并关闭。常规卸载不删用户资料，拒绝 `--delete-app-data` 参数。
- 未改变 appId、app.setName 或默认 `%APPDATA%\Career Assistant` 数据位置；不自动搬迁用户数据库，不增加后台更新服务。
- `public/fonts`：官方 Google Sans 两个原始字体文件；CSS本地 @font-face；`src/controls.tsx` 更新字体披露。MiSans是独立自定义许可，不改编、不随包重分发；需要完全一致的开箱即用MiSans时需另行确认嵌入分发权限。
- `scripts/build-licenses.mjs` 生成依赖清单、全文通知和SHA256；打包到 `resources/licenses`；本地构建不再次联网取许可。
- `scripts/verify-release.mjs` 扩展验证字体、OCR数据、许可清单/哈希、Electron/Chromium通知与原安全fuses/ASAR内容一致性。
- `scripts/smoke-installer.ps1`：只测试明确隔离安装目录，拒绝碰已有安装；临时当前用户注册/快捷方式最终由卸载器清理，不使用手工注册表删除或强杀进程。
- 安装图标为本项目代码绘制的公文包图形，不冒用第三方商标。
