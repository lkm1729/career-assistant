# P02：供应商基础配置与真实文字简历链路

日期：2026-09-15
版本：0.2.0
范围：P02；不是完整 P03/P04，也不代表四种协议或四页 AI 已全部可用。

## 实现

- 设置页新增一套供应商/模型配置、端点预览、密钥输入、保存/删除以及需要单独确认的文本连接测试。
- 后端新增加密连接表与简历版本表，保留 P01 草稿表和设置表。使用 Windows safeStorage；读取公共配置不返回密钥。
- Chat Completions SSE 解析支持跨字节分块、CRLF、空事件和结束标记；拒绝错误/拒绝/截断/超限响应。网络错误不会回显提供商正文。
- 发送确认固定输入快照和配置版本；后端比较当前已保存数据，配置变更后需要重新确认。
- 生成期间单任务锁、主动取消、超时，无自动收费重试。只发送简历页提示词/系统提示词/正文，附加三字段结构约束。
- 完整结果解析为正文、排版建议、设计说明；在一个事务中追加 V1/V2 等正式版本并更新简历工作草稿。旧版和生成前输入正文保留，可只读查看。
- 手动草稿保持 P01 的自动保存；成功后只刷新简历页，避免刷新其他页面时冲掉正在编辑的草稿。
- 提取独立 Modal 组件，避免设置控件和 AI 控件的循环导入。保留已有布局、深浅主题和安全 Markdown。

## 验证与边界

- 16 项单元/服务测试通过：包含原 P01 7 项；新增端点、安全配置、密钥不明文落盘、版本幂等、加密故障、事务失败回滚、流解析、错误状态、格式验证、超时和取消。
- 8 项 Electron E2E：包含 6 项 P01 回归，以及 P02 配置→确认测试→生成→重开→历史→删除连接不删版本，取消/认证错误/格式失败保留旧内容。
- 本机 mock server 核对请求与测试密钥，只发送该页材料。未进行真实供应商或付费模型调用，不能据此宣称所有兼容服务均已验证。
- 视觉检查设置页与生成页面；截图里模拟供应商和模拟正文为测试样本，不随发行数据库打包。
- 类型检查、格式检查与生产构建通过。新包单独输出到 release/0.2.0，保留旧 EXE。

## 本轮本地审查

Standards：检查密钥存储/回传、请求重定向、响应异常的敏感内容、输入校验、事务与队列边界。修复成功回调刷新全局快照导致其他页编辑可能被旧数据覆盖的风险，改为仅刷新简历数据。
