# P01：独立桌面工作区

日期：2026-09-14
状态：已完成本机自动化验收与界面检查。不是完整四合一 AI 产品，不是独立安装包。

## 本轮范围

以四个独立标签页贯穿 React 界面、受限 IPC 和 SQLite 本地持久化，完成提示词/正文/修改要求草稿、主题与选中页面保存。简历和求职信为纵向三区，评分卡在窄窗口变为两列。手动 Markdown 内容可预览、复制和导出；系统提示词可编辑，重置需确认。

供应商管理、AI、解析、评分、正式版本仍不可用且明确标注。上传区域不是可用上传控件；网页链接仅暂存文字，不访问网络。记录对话框只有当前草稿信息，没有假版本。

## 验证

- 存储及安全测试：7 项通过。覆盖隔离与重开、非法输入不覆盖、设置保存、可信页面片段、写入队列排空、失败状态隔离、失败导出保留原文件。
- Electron E2E：6 项通过。覆盖四页草稿与选中页重启恢复、深浅/系统主题和窄窗口、系统提示词隔离及确认恢复、惰性 Markdown 与未启用的 AI、键盘跳转后保存、真实 SQLite 写锁导致的失败与重试。
- TypeScript 检查、生产构建、Prettier 格式检查通过；构建产物是 renderer 与 Electron 入口，不是安装包。
- 实际渲染并检查浅色简历页、深色窄窗口评分页。截图来自隐藏离屏 Electron 的真实 UI，不是设计稿。
- 不执行真实 AI 请求。系统剪贴板、原生导出文件选择器以及干净电脑安装流程未做端到端验证；导出文件服务已有成功/失败测试。

首次截图测试因隐藏窗口没有绘制帧超时；测试模式改为离屏渲染后重跑通过，正常桌面仍为常规窗口。

## Standards 审查

发现 3 项并修复：

1. 跳转链接增加 URL 片段后，完整 URL 比较导致合法 IPC 被拒绝。现在只忽略片段，仍校验文档 URL、发送窗口和主框架；已有单元及桌面回归。
2. 关闭时只等待旧的 Promise 队列。现在等待队列稳定排空，并按标签页保留失败状态；已有延迟写入测试。
3. 直接导出可能先截断旧文件。现在先写入同目录唯一临时文件并刷盘，完成后重命名替换；已有模拟失败保留原件测试。

## Spec 审查

发现 2 项，均为上面的跳转后保存与退出队列问题；修复并验证。明确标注的 P02+ 功能不算 P01 缺失。没有新增跨页资料库或自动流转。

审查为两名只读子代理分别执行 Standards / Spec，主代理修复并回归。无 Git 仓库及历史提交，审查范围是相对初始四个规划文件新增的全部实现，而非 Git diff。没有执行提交或推送。
