## 产品定位和安全边界

- 当前代码的用途是用户侧求职材料整理与生成，没有发现自动投递、批量骚扰、凭证窃取、自动执行模型工具或绕过服务商限制的功能。此为本次代码审查范围内的发现，不是完整安全认证或法律结论。
- 原任务记录显示上游返回会话级 HTTP 403；缺少服务商规则命中和审计日志，不能确定原因，也不能将其归因于某个代码词语。没有通过删除安全校验、自动重试被拒请求或关闭 TLS 校验来“修复”封锁。
- 本地编辑、保存、预览和版本操作可离线使用。应用未内置本地推理模型；用户选择远程供应商并确认生成/探针后，对应请求会发往该供应商。供应商日志留存不受本地保存机制保证。
- 生成/探针需明确确认；密钥仅由主进程使用，远程请求不跟随重定向；渲染器禁用 Node 集成，启用隔离和沙盒。Markdown 不执行 HTML、不加载外部图片或自动打开外部链接。
- 密钥本机加密不等于整库加密：正文、经历、历史与备份仍是未加密 SQLite 内容。
- 未见顶层 LICENSE；本次不擅自替作者选择许可。公开开源发行前仍需作者确认许可证、第三方依赖与字体授权。
