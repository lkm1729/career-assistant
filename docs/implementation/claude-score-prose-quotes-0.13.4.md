# Claude 评分正文引号兼容 · 0.13.4

日期：2026-09-19。范围：用户提供的 Claude 评分响应触发 AI_SCORE_JSON / SEPARATOR_REQUIRED。此前 31–36 优化按用户确认已完成，本轮不重做功能、UI 或历史语义。

## 证据与根因

用户主动提供失败响应。本轮直接从授权附件只读重放，不复制正文到源码、测试夹具、发布包或日志，不读取正式数据库、凭证或调用真实供应商。

- 旧 parseScore 对实际附件稳定重现 AI_SCORE_JSON / SEPARATOR_REQUIRED。
- 去掉唯一完整 JSON 围栏后依然失败，排除围栏为本次原因。
- 11 条 suggestions、2 条 issues 中共有 52 个正文英文双引号未转义。仅转义这些已有引号，标准 JSON.parse 即可解析全文，未补逗号、字段、分数或容器。
- 最小结构：独占一行的 `"**行动**：将"A"改为"B""`。回归使用全新虚构文案，没有用户个人信息。
- 根因是模型输出在问题/建议的引用短语中违反 JSON 字符串转义规则；旧评分语法不支持此偏差。两协议在接收完成后共用此解析链路，并非据此认定协议连接失败。

## 修复边界

1. 强化评分提示词：建议使用中文引号；保留英文引号时必须 JSON 转义，示例由 JSON.stringify 生成；证据原文不改写。
2. 新增 score-prose.ts，由 parseScore 显式启用。普通 decodeScoreJson 调用仍保留原严格边界。
3. 仅匹配 dimensions 数组直接元素下 issues/suggestions 数组的字符串；字符串须独占一行（行首只有缩进，行尾只允许空白及可选逗号），已有内引号必须成对。
4. 拒绝可能的逗号、冒号、容器、注释边界，空引用或 JSON 原子歧义；不跨行猜测，不补缺失引号。单行最多16000字符、最多32对内引号；原700000字符/64层边界保留。
5. 保留已有英文引号及文本，不修改来源ID、证据摘录、分数、summary/example或其他字段。出现偏差时记录 PROSE_QUOTES 提示，继续全部结构/来源/证据/完整性校验。
6. 缺失内容、单引号、重复字段、截断、非法证据仍失败；原历史和当前结果不被失败覆盖，不自动重试付费请求、不自动改变模型结构化能力配置。0.13.3默认关闭的诊断入口保留。

这不是通用 JSON 修复器。格式不在上述有限规则内时仍拒绝；不会保证任意未来 Claude 输出都成功。
