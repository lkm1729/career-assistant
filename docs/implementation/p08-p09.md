# P08 / P09 实施与验收记录

日期：2026-09-16。版本：0.9.0。

## P08 文件与图片资料

- `MaterialStore` 将资料按 `resume` / `score` 页面隔离保存；导入由主进程原生多选对话框取得路径，渲染器不能提交任意路径。
- 离线解析器打包 `pdfjs-dist`、`docx-preview`、Tesseract.js 及英/简体中文语言包；隐藏沙箱窗口使用唯一内存 session，网络、导航、新窗口、权限和 webview 均拒绝。
- PDF 抽取文字并渲染 JPEG 页面；文字不足时使用本机 OCR。PNG/JPEG/WebP 同样 OCR。DOCX 使用本地 HTML 排版器预览，明确标注其不是原始打印版面，完整视觉评分应提供 PDF 或页面截图。
- 每项默认不选；发送前显示资料清单、图像数、文字量和遗漏，用户逐项勾选并确认。失败项保留失败原因，不会自动发送。取消保留已经完成的资料。
- 限制：单文件 12 MiB、单页 16 项、每文件最多解析 8 页、文字 120,000 字、发送最多 8 张图/12 MiB、单图 20M 像素。超限不静默截断。OCR 仅内置 eng/chi_sim。

## P09 简历评分

- 评分页可留空目标进入通用模式，填写目标进入目标模式。只使用评分页正文和本页资料，不读取设计简历页或求职信页。
- 模型只返回四维结构化结果；程序校验分数、四个唯一维度、来源 ID、文字引用和图像页覆盖，并使用 30/30/20/20 权重四舍五入。模型返回的 total 会被忽略。
- 无图像、DOCX 近似页面、模糊/失败/未覆盖页面、冲突或遗漏时显示部分评价，不计算完整总分且不重分配权重。
- 每次成功评价写入独立 `score_records` 历史；失败、取消、格式错误、草稿/配置/资料过期均不保存。

## 已知边界

真实供应商尚未在本次自动化中调用；四协议使用严格本机模拟服务验证线路。视觉评分依赖所选模型实际视觉能力探针/声明。删除资料是数据库逻辑移除，不是安全擦除；历史快照可能保留来源元数据。

## 本机数据限制

本地资料副本（含逻辑移除行）总上限 512 MiB，达到上限会拒绝继续导入，不自动删除历史。文件读取使用有界循环并检测读取期间体积变化；DOCX 解压预检在隔离解析窗口而非主进程进行。
