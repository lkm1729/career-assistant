- 新增 `shared/matching.ts`，定义岗位要求、硬性条件、四种状态（已体现、部分体现、未找到证据、待确认）、证据和申请建议的数据契约。

- 保留已有求职信正文生成、继续调整、版本切换、恢复和回收站隔离能力。

**尚未完成：**P11 完整桌面回归、岗位/简历/补充证据分组策略、求职信独立验收报告，以及后续 P12 网页资料接入。
