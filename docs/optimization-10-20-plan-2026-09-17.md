## O1：资料逐项用途与批量管理

已核对：Material 有逐项 purpose；Materials.tsx 的文件导入、网页批量导入仍采用统一用途参数。

- 文件支持一次多选，链接支持一次多条输入；每条资料独立设置和修改用途。
- 导入前展示逐项清单和用途；保留批量设置作为快捷操作，但不强迫全部同类。
- 导入后逐项用途可修改并持久保存；用途变更必须使相关发送预览/确认快照失效，避免发送旧用途。
- 设计简历、岗位匹配、撰写求职信均可补充个人项目网页，默认作为补充证据，不当作目标岗位。
- 核对网页用途是否需要支持简历网页，确保第 10 项的不同网页用途不被当前 job/evidence 二选一限制。
- “参与 AI 发送”的选择与“选择待删除项”分开；新增多选、全选、取消选择、批量删除。
- 删除前显示数量、名称与影响范围；运行中被使用的资料不可发生破坏性修改。
- 删除只针对本应用资料副本，不删除用户原始文件；旧运行的历史证据快照保持可解释。
- 某个网页失败不丢弃其他成功项，不自动读取未确认链接。

验收：混合简历、图片、岗位文件与项目链接，独立分类、修改后重启、发送预览一致；跨页隔离；部分导入失败；全选删除取消/确认；来源证据回归。

## O3：匹配展示、提示降噪与建议排版

已核对：MatchPanel.tsx 当前展示 coverage，属于证据覆盖率，不等于岗位匹配分数；有现有逐项引用校验。

### 第 12 项

- 新增水平指标条与 0–100 匹配分数，明确它是“基于本次材料的岗位匹配度”，不是录用概率。
- 不直接把 coverage 改名为匹配度。实施前定义可复算的评分规则，解释已体现、部分体现、未找到证据、待确认的处理。
- 推荐应用依据已验证的要求/证据计算分数，而不是模型任意输出数字；O3实施规则为硬性项权重2、其他项权重1，已体现1、部分体现0.5、未找到/待确认0；规则与限制在界面公开，不冒充招聘效果校准。
- 显式展示证据不足和硬性条件限制；不能因低覆盖而暗示用户没有能力，也不能让总分掩盖硬性条件未满足。
- 指标下方一张结论卡，分为“匹配依据”“仍有局限”“申请/面试前建议”；保留展开查看逐项证据。
- 老记录缺少新字段时使用兼容展示，不偷偷改写历史结果、不自动调用 AI 补齐。

### 第 13 项

- 移除用户列出的三类例行红字在结果、资料预览、发送清单中的重复呈现，不只是换个区域再次重复。
- 正常导入来源信息使用普通说明或按需展开的技术详情；红色留给实际失败或阻止继续的问题。
- 不删除网页读取、网络授权、来源确认、提示注入隔离与证据校验等底层保护；真实缺失内容或冲突仍需简短可操作提示。

### 第 16 项

- 简历评分和求职信建议使用固定结构：小标题、项目符号、关键词加粗；结构化 JSON 字段可渲染为统一卡片。
- 提示词约束与渲染器协同，不承诺仅靠一句提示就能强制任意模型正确排版。
- 与既有严格输出契约兼容；旧纯文本建议可读，模型格式错误不损坏历史或输出正文。
- Markdown 不启用任意 HTML 或远程图片自动加载；正文导出不混入建议面板的格式标记。

验收：评分规则边界/未知项/硬条件、非法引用、老记录展示、错误格式、Markdown 安全、无重复例行红字、明暗主题。

## O4：清空当前工作台成果

本轮按以下安全语义实现：清空当前成果，不含永久清除历史。

- 四个工具均新增“清空当前结果”；设计简历、求职信清空当前生成正文及配套建议，评分、匹配清空当前展示的评估。
- 保留输入资料、供应商/模型设置和历史记录。清空历史须是另一个明确确认的操作，不能与清空工作台混同。
- 说明手动编辑内容是否也将清空；提供可恢复的切换前草稿/撤销入口。
- 清空必须持久化，重启不能自动又选回最新成果；历史恢复操作仍可使用。
- 运行中禁用清空，或先由用户确认取消运行并等待结束，防止迟到响应把结果重新写回。

验收：四页独立清空、取消确认、恢复、重启、草稿保护、运行中竞态、历史与附件未被删除。

## O5：HTTP 错误展示与模型发现

已核对：shared/diagnostics.ts 已有 httpStatus 与 AI_HTTP_*，第 14 项优先改善展示而非另造错误体系。

- 有真实 HTTP 状态时突出显示“429 / 500 / 502 / 503 + 中文解释 + 下一步建议”。
- 本地校验失败、断网、超时或 JSON/证据失败无 HTTP 响应时，不伪装成服务器 500；内部诊断码保留在详情中。
- 不展示密钥、原始服务响应、个人资料或带敏感查询参数的地址。
- 在新增模型处增加“获取模型列表”，用户明确点击才请求当前供应商；不携带简历等工作台资料。
- 实施时按供应商实际协议查阅并核对官方列表接口；不按模型品牌猜协议。
- 支持搜索、多选导入、去重、分页（若接口有）、超时取消与旁侧反馈；保留手动输入模型 ID。
- 接口不支持、列表为空、权限不足给出准确反馈，不把模型列表可见当作推理调用可用。
- 不根据模型名字默认为支持图片、工具或特定参数，不自动发起收费连通性测试。

验收：各协议模拟列表、无列表接口、分页、重复ID、鉴权失败、限流、取消；真实供应商测试单独授权、单独记录。
