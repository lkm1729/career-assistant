## 本轮范围与边界

P06/P07 接入既有简历生成、继续调整、取消、版本保存/恢复和模型能力测试。图片能力测试仅使用内置样本；不提前宣称实现 P08 的用户文件/图片上传。

Gemini / Anthropic 的思考参数语义不同，本批不把通用 reasoningEffort 直接套用；参数不支持时明确拒绝。Gemini 用模型专属流式路径与 x-goog-api-key；Anthropic 用 Messages 与 x-api-key，必填 max_tokens 未指定时为 4096，真实模型兼容性仍需要用户验证。

本批不会引入自动上传、云同步、工具执行、远程会话链或调试入口回退。0.5.1 的发布包加固继续保留。
