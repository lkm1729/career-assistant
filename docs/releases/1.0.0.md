# Career Assistant 1.0.0

## 正式发布

Career Assistant 1.0.0 是首个正式开源版本。0.13.7 作为最终测试版本后，本次发布将应用元数据、Windows ZIP 构建配置、免安装 ZIP、第三方许可证清单和校验文件统一到 1.0.0。

## 主要能力

- Windows x64 桌面应用，四个独立 AI 求职工作台。
- 本地优先：资料、草稿、历史和供应商配置留在本机。
- 支持 PDF、DOCX、图片、文字和经确认的公开网页资料。
- 支持 Chat Completions、OpenAI Responses、Gemini 原生协议和 Anthropic Messages 原生协议。
- 发送前显示资料清单并要求确认；未选择的资料不会发送。
- 内置 PDF/DOCX/OCR 处理资源，无需额外安装 Node、Python、Office 或在线字体即可启动已打包应用。
- 包含第三方依赖许可证清单、字体/OCR 来源说明和 SHA256 校验文件。

## 验证

- 类型检查：通过。
- 格式检查：通过。
- 单元/服务测试：828 项通过。
- `1.0.0` 免安装 ZIP、ASAR 完整性、Electron fuse、许可证清单和资源哈希：已通过 `node scripts/verify-release.mjs release/1.0.0/win-unpacked`；发布文件 SHA256 已生成。

## 已知边界

- Windows ZIP 发布包当前未签名。
- 真实供应商行为需要使用用户自己的供应商配置单独验证。
- 独立干净机器验证不是本机测试的自动结论。
- 第三方供应商的服务器日志、代理日志、计费记录和数据保留政策不由本项目控制。
