# Career Assistant 1.1.0

## 更新内容

- 新增独立的“面试问答”工作区：输入岗位与简历，选择本页文件、图片、剪贴板内容及经确认的多个网页链接，生成约20组英文面试问题与参考答案，并显示小字中文对照。
- 支持本页系统提示词预设、供应商与模型选择、发送前资料确认，以及问答生成历史的查看和管理。
- 优化生成过程提示和结果展示，显示供应商、模型、接口协议与本地生成时间。
- 面试问答的长时请求按接口协议设置有限等待上限，降低慢速生成被过早判定超时的概率；取消、超时或不完整结果不会保存或自动重试。

## 下载与使用

发布时提供 Windows x64 免安装 ZIP `Career-Assistant-1.1.0-win-x64.zip` 和 `SHA256SUMS.txt`。核对校验值后解压到新目录，运行 `Career Assistant.exe`；不要在 ZIP 内直接运行。发布文件以 GitHub Release 实际资源清单为准。

应用数据保存在 `%APPDATA%\Career Assistant`，替换或重新解压程序不会清除既有 Base URL、API Key 与历史。需要测试全新状态时，请使用独立的 Windows 用户/隔离配置，不要把现有数据目录放进发布包；备份与清理现有配置应由用户自行决定。

## 隐私与限制

资料和历史留在本机，只有用户明确确认的内容才发送给所选供应商或用于网页读取。供应商的服务器日志、代理日志、数据保留和计费政策不受本项目控制；请求超时不代表供应商未计费。Windows ZIP 未签名；真实供应商与独立干净机器使用情况需另行验证。
