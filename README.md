# Career Assistant

Windows 本地优先的 AI 求职助手，帮助你整理求职资料、分析岗位、生成简历内容和求职信，并在发送前明确确认要提供给 AI 的资料。注：此项目由**GPT-6 Astra**辅助开发

## 项目介绍

Career Assistant 面向 Windows x64，提供五个相互独立的 AI 求职工作台：简历/求职材料、岗位匹配、岗位评分、求职信和面试问答。项目强调本地优先和资料隔离，未选择的资料不会自动跨页面共享或发送。

应用支持本地处理 PDF、DOCX、图片和文字资料，也支持在明确确认后读取公开网页内容。AI 请求由用户配置的供应商和模型执行，应用不会自动上传资料、云同步或收集遥测数据。

## 主要功能

- **五个独立工作台**：简历与求职材料、岗位匹配、岗位评分、求职信、面试问答。
- **双语面试问答**：结合岗位、简历和明确选定的资料生成20组英文问答及中文对照，支持本页历史管理。
- **多种资料格式**：PDF、DOCX、图片、纯文本，以及经确认的公开 HTTPS 网页。
- **多供应商支持**：Chat Completions、OpenAI Responses、Gemini 原生协议和 Anthropic Messages 原生协议。
- **发送前确认**：导入资料后可以预览、设置用途、选择发送内容，并在请求前再次确认。
- **证据约束**：岗位匹配和评分结果引用已验证来源，不把模型的未经验证内容当作事实。
- **本地历史与恢复**：支持版本记录、恢复、回滚、清空和撤销，失败请求不会覆盖已有结果。
- **离线内置资源**：已打包应用包含 PDF、DOCX 和 OCR 运行资源，不需要额外安装 Node.js、Python、Office 或在线字体即可启动。
- **安全边界**：资料、草稿、历史和供应商配置保存在本机；第三方供应商的服务器日志和数据保留政策不由本项目控制。

## 如何安装和使用

### 使用免安装 ZIP

1. 下载 `Career-Assistant-1.1.0-win-x64.zip`。
2. 将 ZIP 完整解压到新的本地目录。
3. 运行目录中的 `Career Assistant.exe`。
4. 不要直接从 ZIP 压缩包内启动程序。

### 第一次使用

1. 在设置中添加供应商端点、模型和 API Key。
2. 选择一个工作台，例如岗位匹配或求职信。
3. 导入 PDF、DOCX、图片或文字资料。
4. 为资料设置用途并预览解析结果。
5. 明确选择允许发送的资料。
6. 在发送确认窗口核对模型、资料清单和请求内容。
7. 确认后运行 AI 请求，并从本地历史中查看或恢复结果。

应用数据保存在：

```text
%APPDATA%\Career Assistant
```

替换解压目录不会删除已有应用数据。重要资料请自行备份；如需从全新状态开始，请在关闭应用后删除上述数据目录。

## 隐私与数据

- 未选择的资料不会发送给 AI 供应商。
- 网页读取需要用户明确确认。
- 页面之间不会自动共享资料或提示词副本。
- 应用不包含自动遥测、云同步或后台上传。
- API Key 由应用在本地加密保存，不写入 README、测试报告或普通诊断信息。
- 供应商自己的服务器日志、代理日志、计费记录和数据保留策略需要用户单独查看其政策。
